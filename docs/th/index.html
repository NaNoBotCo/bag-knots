หนังยาง

หนังยางรัดปากถุงได้เป็นสิบแบบ นี่คือแบบที่เจอบ่อยที่สุด วาดตั้งแต่ถุงยังเปิดจนยางรอบสุดท้าย แล้วแกะด้วยมือ แล้วตัดด้วยกรรไกร แตะขั้นไหนก็ข้ามไปขั้นนั้นได้

ถุงพอง เกี่ยวปลาย

แกง ต้ม ของน้ำทุกอย่าง ถุงร้านข้าวแกง

มัด

  1. ตักใส่ราวสองในสาม เหลือปากถุงว่างไว้
  2. รวบปากถุงด้วยสองมือ ดึงให้ตึง แล้วปิดโดยขังอากาศไว้ข้างใน
  3. บิดคอถุงสองสามรอบ เกลียวนี้ขังอากาศไว้
  4. คล้องหนังยางปลายหนึ่งไว้ที่นิ้ว ดึงยืดอ้อมคอถุง
  5. พันสามสี่รอบ รอบใหม่ขึ้นไปเหนือรอบเก่า บางร้านพันยางรอบคอ บางร้านจับยางไว้แล้วหมุนถุง
  6. รอบสุดท้าย ดึงยางข้ามปลายถุงแล้วปล่อยลงรัดคอ รอบนี้ล็อกรอบข้างล่างไว้

แกะมือ

  1. หายางรอบที่คล้องข้ามปลายถุง รูดขึ้นแล้วหลุดออกทางปลาย
  2. รอบที่เหลือคลายออก หมุนถุงกลับทาง หรือแกะยางออกทีละรอบ
  3. คลายเกลียวคอถุง ตั้งถุงไว้ตรงๆ ข้างในคือแกงร้อน

กรรไกร

  1. ใช้กรรไกร ตั้งถุงในชามก่อน
  2. กรรไกรครัว อ้าใบไว้ ต่ำกว่ายางรอบล่างสุดราว 1 ซม. ขวางคอถุงที่บิดไว้
  3. ตัดฉับเดียวตรงๆ จับคอถุงใต้รอยตัดไว้ให้ถุงตั้งอยู่
  4. ปลาย เกลียว และยาง หลุดออกเป็นชิ้นเดียว เทได้เลย

เบียร์ ถุงพองคืออากาศที่ตั้งใจขังไว้ กันอาหารโดนบีบ

พับปากถุง เกี่ยวนิ้วก้อย

แกงและต้ม ตามวิธีที่ครัวคุณต๋อยสอน

มัด

  1. ถุงหนึ่งใบ หนังยางหนึ่งเส้น
  2. จับปากถุงสองข้าง ดึงให้ตึง
  3. พับปากถุงลงสองทบ
  4. พับปากถุงข้างซ้ายข้างขวาเข้าหากลาง ขังอากาศไว้ ถุงจะพอง
  5. เกี่ยวหนังยางไว้ที่นิ้วก้อย พันรอบปากถุงหนึ่งรอบ
  6. คล้องยางกับนิ้วก้อยอีกครั้ง เป็นปม
  7. หมุนยางรัดปากถุงอีกสามรอบ
  8. เหน็บปลายยางไว้ที่ขอบบน

แกะมือ

  1. ดึงปลายยางออก ปมก็คลาย
  2. รอบยางหลวม รูดออกได้

กรรไกร

  1. ใช้กรรไกร ตั้งถุงในชาม
  2. ตัดใต้ยาง ขวางคอถุงที่พับไว้
  3. ตัด
  4. ปากถุงที่พับไว้หลุดออกพร้อมยาง

แนน ปลายที่เหน็บไว้! นั่นแหละที่ดึงเปิด!

พับปลายสอดยาง กระตุกทีเดียว

ถุงรัดยางทุกแบบ ร้านที่อยากให้ลูกค้าแกะง่าย

มัด

  1. รวบ ขังอากาศ บิดคอ แบบถุงพอง
  2. พันยางรอบคอสองรอบ
  3. พับปลายถุงลงแนบคอ
  4. รอบสุดท้ายรัดทั้งคอถุงและปลายที่พับไว้

แกะมือ

  1. กระตุกปลายถุงขึ้นแรงๆ ครั้งเดียว ปลายหลุดจากใต้ยาง ยางก็คลายหลุด
  2. คลายเกลียวแล้วเปิด

กรรไกร

  1. ใช้กรรไกรแบบถุงไม่ขาด ตัดยาง ไม่ตัดถุง
  2. สอดใบกรรไกรใบหนึ่งแนบใต้ยางทุกรอบ ตามแนวคอถุง ปลายใบชี้ไปทางปลายถุง ให้พลาสติกอยู่นอกใบกรรไกร
  3. ตัดฉับเดียว ยางขาดทุกรอบ
  4. ยางหลุดร่วง ถุงยังปิดด้วยเกลียว คลายเกลียวเหนือชาม

แนน กระตุกทีเดียว ยางหลุดทั้งเส้น!

ถุงน้ำจิ้มฝากมากับถุงใหญ่

ต้มกับพริก ก๋วยเตี๋ยวกับพริกน้ำส้ม ยางเส้นเดียวรัดสองถุง

มัด

  1. ถุงใหญ่รวบและบิดคอแล้ว
  2. พันยางรอบคอสองรอบ
  3. วางคอถุงน้ำจิ้มที่บิดไว้แนบคอถุงใหญ่
  4. พันต่อ รอบต่อไปรัดทั้งสองคอ
  5. ล็อกข้ามปลายถุงใหญ่

แกะมือ

  1. รูดยางล็อกออกทางปลาย
  2. คลายยาง ถุงน้ำจิ้มหลุด รับไว้

กรรไกร

  1. ใช้กรรไกร ถ้าตัดใต้ยาง ถุงจะเปิดทั้งสองใบพร้อมกัน ตัดที่ยางดีกว่า
  2. สอดใบกรรไกรใต้รอบยาง ตามแนวคอ ปลายชี้ไปทางปลายถุง
  3. ตัด
  4. ยางหลุด ทั้งสองถุงยังบิดปิดอยู่ เปิดแต่ละถุงเหนือจานของมัน
